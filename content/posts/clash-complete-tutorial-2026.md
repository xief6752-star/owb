Clash 是目前最受欢迎的科学上网客户端，支持多平台、功能强大且易于使用。本教程将手把手教您从零开始使用 Clash。

## 一、什么是 Clash？

### Clash 简介

**Clash** 是一个基于规则的跨平台代理软件核心程序。

**主要特点：**
- ✅ 支持多种代理协议（SS、V2Ray、Trojan）
- ✅ 强大的规则分流功能
- ✅ 跨平台支持
- ✅ 图形界面友好
- ✅ 活跃的社区支持

---

### Clash 家族成员

| 客户端 | 平台 | 特点 | 推荐度 |
|--------|------|------|--------|
| **Clash for Windows** | Windows | 功能最全、最稳定 | ⭐⭐⭐⭐⭐ |
| **ClashX Pro** | macOS | 原生体验、性能好 | ⭐⭐⭐⭐⭐ |
| **Clash Verge** | Win/Mac/Linux | 新一代、界面美观 | ⭐⭐⭐⭐⭐ |
| **Clash for Android** | Android | 开源免费 | ⭐⭐⭐⭐⭐ |
| **Stash** | iOS | 付费，功能强大 | ⭐⭐⭐⭐ |

**本教程重点：** Clash for Windows 和 ClashX Pro

## 二、Windows 平台使用教程

### 步骤 1：下载 Clash for Windows

#### 方法 A：GitHub 下载（推荐）

1. 访问 GitHub 官方仓库
2. 找到 Releases 页面
3. 下载最新版本的 `.exe` 安装包

**下载链接示例：**
```
Clash.for.Windows.Setup.0.20.39.exe
```

#### 方法 B：备用下载源

如果 GitHub 无法访问，可以从以下渠道下载：
- 机场官网提供的客户端下载页
- 云盘分享链接（需确保来源可信）

⚠️ **安全提示：** 只从官方或可信来源下载，避免木马病毒。

---

### 步骤 2：安装 Clash for Windows

1. **双击安装包**
   - 如果 Windows 提示"无法验证发布者"，点击"仍要运行"

2. **选择安装路径**
   - 默认路径：`C:\Users\你的用户名\AppData\Local\Programs\Clash for Windows`
   - 可自定义路径

3. **完成安装**
   - 等待安装完成
   - 勾选"启动 Clash for Windows"

---

### 步骤 3：获取订阅链接

**什么是订阅链接？**
- 机场提供的配置文件 URL
- 包含所有节点信息
- 定期更新节点

**如何获取：**

1. 登录您购买的机场网站
2. 找到"订阅中心"或"客户端下载"页面
3. 复制 Clash 订阅链接

**示例：**
```
https://example.com/api/v1/client/subscribe?token=xxxxx
```

⚠️ **重要：** 订阅链接是您的私密信息，不要泄露给他人。

---

### 步骤 4：导入订阅配置

1. **打开 Clash for Windows**
   - 主界面左侧找到 "Profiles"（配置）

2. **导入订阅链接**
   - 点击输入框
   - 粘贴订阅链接
   - 点击 "Download"（下载）

3. **等待下载完成**
   - 出现配置文件名称
   - 显示节点数量

4. **选择配置文件**
   - 点击配置文件名
   - 激活该配置（颜色变绿）

---

### 步骤 5：选择代理模式

**代理模式说明：**

| 模式 | 说明 | 使用场景 |
|------|------|----------|
| **全局模式** | 所有流量走代理 | 访问全外网内容 |
| **规则模式** | 自动分流（推荐） | 日常使用 |
| **直连模式** | 不走代理 | 临时关闭代理 |

**推荐设置：规则模式**

1. 主界面左侧 "General"（常规）
2. 找到 "Mode"（模式）
3. 选择 "Rule"（规则）

---

### 步骤 6：选择节点

1. **打开 Proxies（代理）页面**
   - 主界面左侧点击 "Proxies"

2. **查看节点列表**
   - 显示所有可用节点
   - 包含延迟信息

3. **测试延迟**
   - 点击 "Delay Test"（延迟测试）
   - 等待测试完成
   - 延迟越低越好（<100ms 为优秀）

4. **选择节点**
   - 点击要使用的节点
   - 推荐选择延迟低的香港/日本节点

---

### 步骤 7：开启系统代理

1. **打开系统代理开关**
   - 主界面 "General" 页面
   - 打开 "System Proxy"（系统代理）开关

2. **确认代理已启用**
   - 任务栏图标变为彩色
   - 浏览器可访问 Google

---

### 步骤 8：验证连接

**测试方法 1：访问 Google**
- 打开浏览器
- 访问 https://www.google.com
- 能正常打开说明成功

**测试方法 2：IP 地址检测**
- 访问 https://ip.sb
- 显示的 IP 应该是代理节点的 IP

**测试方法 3：YouTube 播放**
- 打开 YouTube
- 播放任意视频
- 能流畅播放说明速度正常

---

## 三、macOS 平台使用教程

### 步骤 1：下载 ClashX Pro

1. 访问 GitHub 官方仓库
2. 下载最新版 `.dmg` 文件

**文件名示例：**
```
ClashX.Pro.1.96.0.dmg
```

---

### 步骤 2：安装 ClashX Pro

1. **打开 DMG 文件**
   - 双击下载的 `.dmg` 文件

2. **拖动到应用程序**
   - 将 ClashX Pro 图标拖到 Applications 文件夹

3. **首次启动**
   - 在 Launchpad 或应用程序文件夹中找到 ClashX Pro
   - 双击启动

4. **允许运行**
   - macOS 可能提示"无法验证开发者"
   - 打开"系统设置" → "隐私与安全性"
   - 点击"仍要打开"

---

### 步骤 3：导入订阅配置

1. **点击菜单栏图标**
   - 屏幕顶部出现 ClashX 图标（猫咪）

2. **配置 → 托管配置 → 管理**
   - 点击"添加"

3. **粘贴订阅链接**
   - 输入配置名称（如：我的机场）
   - 粘贴订阅链接
   - 点击"确定"

4. **更新配置**
   - 右键菜单 → 配置 → 更新配置
   - 等待更新完成

---

### 步骤 4：开启代理

1. **设置为系统代理**
   - 点击菜单栏图标
   - 勾选"设置为系统代理"

2. **选择代理模式**
   - 选择"规则判断"（Rule）

3. **选择节点**
   - 代理 → Proxy → 选择节点

4. **测试连接**
   - 访问 Google 验证

---

## 四、Android 平台使用教程

### 步骤 1：下载 Clash for Android

#### 方法 A：GitHub 下载

1. 访问 GitHub 仓库
2. 下载 APK 文件

**文件名示例：**
```
cfa-2.5.12-foss-universal-release.apk
```

#### 方法 B：Google Play（需翻墙）

- 搜索"Clash for Android"
- 安装官方版本

---

### 步骤 2：安装和导入配置

1. **安装 APK**
   - 允许安装未知来源应用

2. **打开应用**
   - 点击"配置"

3. **添加配置文件**
   - 点击右上角 "+"
   - 选择"URL"
   - 粘贴订阅链接
   - 点击"保存"

4. **下载配置**
   - 点击配置文件
   - 等待下载完成

---

### 步骤 3：启动代理

1. **选择配置文件**
   - 点击刚下载的配置

2. **选择节点**
   - 点击"代理"标签
   - 选择节点

3. **启动服务**
   - 返回首页
   - 点击右下角开关按钮
   - 允许 VPN 连接请求

4. **验证连接**
   - 打开浏览器
   - 访问 Google

## 六、常见问题解决

### 问题 1：无法下载配置

**原因：**
- 订阅链接错误
- 网络问题
- 订阅已过期

**解决方法：**
1. 检查订阅链接是否完整
2. 确认机场账号是否有效
3. 尝试切换网络（WiFi/4G）
4. 联系机场客服

---

### 问题 2：连接后无法上网

**原因：**
- 系统代理未开启
- 节点不可用
- 防火墙拦截

**解决方法：**

1. **确认系统代理已开启**
   - Clash for Windows：System Proxy 开关打开
   - ClashX：勾选"设置为系统代理"

2. **更换节点**
   - 测试延迟
   - 选择延迟低的节点

3. **检查防火墙**
   - Windows：允许 Clash 通过防火墙
   - macOS：系统设置 → 安全性 → 防火墙

---

### 问题 3：速度慢、视频卡顿

**原因：**
- 节点负载高
- 本地网络问题
- 高峰期拥堵

**解决方法：**

1. **更换节点**
   - 选择延迟更低的节点
   - 避开热门节点

2. **测试本地网速**
   - 关闭代理测试
   - 确认不是本地网络问题

3. **联系机场客服**
   - 反馈节点问题
   - 获取备用节点

---

### 问题 4：规则分流不生效

**原因：**
- 代理模式设置错误
- 规则配置问题

**解决方法：**

1. **检查代理模式**
   - 确保选择"Rule"（规则）模式
   - 不要选择"Global"（全局）

2. **更新规则**
   - Clash for Windows：Settings → Update GeoIP Database

3. **重启客户端**

---

### 问题 5：无法访问国内网站

**原因：**
- 全局模式导致
- 规则配置错误

**解决方法：**

1. **切换到规则模式**
   - 不要使用全局模式

2. **更新配置**
   - 重新下载订阅配置

3. **临时关闭代理**
   - 访问国内网站时关闭系统代理

---

## 七、进阶技巧

### 1. 自定义规则

**适用场景：**
- 某些网站需要特定节点
- 自定义分流规则

**操作方法（Clash for Windows）：**

1. Settings → Profiles → Edit
2. 添加自定义规则
3. 保存并重启

---

### 2. TUN 模式

**什么是 TUN 模式：**
- 虚拟网卡模式
- 可代理所有应用（包括命令行）

**启用方法：**

1. Clash for Windows → General
2. 打开 "TUN Mode"
3. 允许安装虚拟网卡驱动

---

### 3. 定时更新订阅

**设置自动更新：**

1. Clash for Windows → Settings
2. Auto Update Interval: 24
3. 每天自动更新配置
