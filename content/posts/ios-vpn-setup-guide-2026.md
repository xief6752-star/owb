iOS 设备（iPhone/iPad）的科学上网相对 Android 更复杂，主要因为 App Store 的地区限制。本教程将手把手教您完整的 iOS 翻墙流程。

## 一、为什么 iOS 翻墙比较复杂？

### 核心问题

**中国区 App Store 已下架所有 VPN 类应用**

- Shadowrocket、Surge、Quantumult X 等全部下架
- 必须使用**非中国区 Apple ID** 才能下载
- 需要付费购买（$2.99 - $7.99）

## 四、方案 A：注册美区 Apple ID

### 步骤 1：准备材料

**需要准备：**
- 一个**未注册过 Apple ID** 的邮箱（Gmail/Outlook）
- 美国地址（网上随便找一个）
- 美国电话号码（可选，用于验证）

**推荐免税州地址（避免被扣税）：**

```
州：Oregon（俄勒冈州）
城市：Portland
邮编：97205
街道地址：123 SW Main St
电话：+1 (503) 123-4567
```

---

### 步骤 2：注册流程

#### 1. 访问 Apple ID 注册页面

打开 Safari 浏览器，访问：
```
https://appleid.apple.com/account
```

#### 2. 填写注册信息

| 项目 | 填写内容 |
|------|----------|
| **姓名** | 随意填写英文名 |
| **国家/地区** | **United States**（美国）⚠️ |
| **出生日期** | 满 18 岁的日期 |
| **邮箱** | 你的邮箱（未注册过的）|
| **密码** | 设置一个强密码 |
| **电话号码** | 中国 +86 手机号也可以 |

⚠️ **重点：国家/地区必须选 United States**

#### 3. 验证邮箱

- Apple 会发送验证码到你的邮箱
- 输入验证码完成验证

#### 4. 验证手机号

- 输入手机号（+86 中国手机号也可以）
- 输入短信验证码

---

### 步骤 3：完善美区信息

#### 1. 在 iPhone 上登录 App Store

- ⚠️ **不要在"设置"中登录，只在 App Store 登录**
- 打开 App Store
- 点击右上角头像
- 退出当前账号
- 登录新注册的美区账号

#### 2. 同意条款

- 点击"Review"（查看）
- 勾选"Agree to Terms and Conditions"
- 点击"Next"

#### 3. 填写付款和送货信息

**Payment Method（付款方式）：**
- 选择 **None**（无）

**Billing Address（账单地址）：**

| 项目 | 填写内容 |
|------|----------|
| **First Name** | 你的英文名 |
| **Last Name** | 你的英文姓 |
| **Street** | 123 SW Main St |
| **City** | Portland |
| **State** | Oregon |
| **Zip Code** | 97205 |
| **Phone** | +1 (503) 123-4567 |

#### 4. 完成设置

- 点击"Next"
- 看到"Your account is now active in the US Store"
- 美区 Apple ID 注册完成！✅

## 五、方案 B：购买成品账号

### 哪里购买？

**推荐渠道：**

1. **淘宝/闲鱼**
   - 搜索"美区 Apple ID"
   - 价格：¥5-20
   - 注意：选择信誉高的卖家

2. **专业网站**
   - 独享账号：¥20-50
   - 共享账号：¥5-15（不推荐）

### ⚠️ 购买注意事项

1. **只买独享账号，不要买共享账号**
   - 共享账号风险高（可能被锁定）
   - 独享账号更安全

2. **只在 App Store 登录，不要在"设置"登录**
   - 避免账号被锁或数据丢失

3. **购买后立即改密码**
   - 保护账号安全

## 八、配置 Shadowrocket

### 步骤 1：获取订阅链接

1. 登录你的机场网站
2. 找到"订阅中心"或"客户端配置"
3. 复制 Shadowrocket/通用订阅链接

**示例：**
```
https://example.com/api/v1/client/subscribe?token=xxxxx
```

---

### 步骤 2：导入订阅

#### 方法 A：直接导入（推荐）

1. **打开 Shadowrocket**

2. **添加订阅**
   - 点击右上角 "+"
   - 选择 "Subscribe"（订阅）

3. **粘贴订阅链接**
   - URL：粘贴订阅链接
   - 备注：填写机场名称（如：云图）
   - 点击"完成"

4. **更新订阅**
   - 右滑订阅项
   - 点击"更新"
   - 等待节点加载

---

#### 方法 B：扫码导入

1. 在机场网站找到订阅二维码
2. 打开 Shadowrocket
3. 点击扫描图标
4. 扫描二维码
5. 自动导入

---

### 步骤 3：选择节点

1. **回到首页**
   - 查看节点列表

2. **测试延迟**
   - 点击"连通性测试"
   - 等待测试完成
   - 绿色数字 = 延迟（越小越好）

3. **选择节点**
   - 点击节点名称切换
   - 推荐选择：
     - 香港节点（延迟 10-30ms）
     - 日本节点（延迟 40-60ms）
     - 新加坡节点（延迟 50-80ms）

---

### 步骤 4：启动代理

1. **点击顶部开关**
   - 首次使用会弹出 VPN 配置请求
   - 点击"允许"

2. **验证 Face ID/Touch ID**
   - 输入密码确认

3. **查看状态**
   - 顶部出现 VPN 图标 ✅
   - 表示已连接

4. **测试连接**
   - 打开 Safari
   - 访问 google.com
   - 能打开说明成功！

## 九、Shadowrocket 进阶设置

### 1. 配置代理模式

**路径：** 首页 → 全局路由

**模式说明：**

| 模式 | 说明 | 使用场景 |
|------|------|----------|
| **配置** | 根据规则分流（推荐）| 日常使用 |
| **代理** | 全部走代理 | 访问纯外网内容 |
| **直连** | 不走代理 | 临时关闭 |
| **场景** | 自动切换 | 高级用户 |

**推荐：配置模式**（自动分流）

---

### 2. 自定义规则

#### 添加规则

1. 首页 → 配置 → 点击当前配置
2. 规则 → 添加规则
3. 类型选择：
   - DOMAIN-SUFFIX（域名后缀）
   - DOMAIN-KEYWORD（域名关键词）
   - IP-CIDR（IP 段）

#### 常用规则示例

```
# Netflix 走代理
DOMAIN-KEYWORD,netflix,PROXY

# 国内网站直连
DOMAIN-SUFFIX,baidu.com,DIRECT
DOMAIN-SUFFIX,taobao.com,DIRECT

# ChatGPT 走美国节点
DOMAIN-SUFFIX,openai.com,🇺🇸 美国节点
```

---

### 3. 订阅自动更新

**路径：** 设置 → 服务器订阅

**建议设置：**
- 自动更新：开启
- 更新间隔：24 小时
- 后台更新：开启

---

### 4. 流量统计

**查看用量：**
- 首页 → 统计
- 查看今日/本周/本月流量

**重置统计：**
- 设置 → 其他 → 重置统计

## 十一、常见问题解决

### 问题 1：无法连接

**原因：**
- 节点失效
- 订阅过期
- 网络问题

**解决方法：**

1. **更新订阅**
   - 右滑订阅 → 更新
   - 等待节点刷新

2. **更换节点**
   - 测试延迟
   - 选择延迟低的节点

3. **检查订阅**
   - 登录机场网站
   - 确认账号有效
   - 确认流量未用完

---

### 问题 2：速度慢

**原因：**
- 节点负载高
- 本地网络慢
- 高峰期拥堵

**解决方法：**

1. **更换节点**
   - 避开热门节点
   - 选择负载低的

2. **更换时段**
   - 避开晚高峰（19:00-23:00）

3. **升级套餐**
   - 考虑高级套餐（带宽更大）

---

### 问题 3：国内网站打不开

**原因：**
- 使用了全局模式
- 规则配置错误

**解决方法：**

**Shadowrocket：**
- 全局路由 → 改为"配置"

**Stash：**
- 确保规则模式为 "Rule"

---

### 问题 4：App Store 无法下载

**原因：**
- Apple ID 地区问题
- 付款方式问题
- 账号被锁

**解决方法：**

1. **确认地区**
   - App Store → 头像
   - 查看是否为美区

2. **检查付款方式**
   - 设置 → Apple ID → 付款
   - 确保有余额或绑定了卡

3. **重新登录**
   - 退出 App Store
   - 重新登录美区账号

---

### 问题 5：订阅导入失败

**原因：**
- 订阅链接错误
- 网络问题
- 订阅格式不兼容

**解决方法：**

1. **检查链接**
   - 确保链接完整
   - 没有多余空格

2. **换个网络**
   - 切换 WiFi/4G

3. **联系客服**
   - 机场客服获取正确链接
