## 📱 iOS（iPhone / iPad）配置教程

### 方法一：Shadowrocket（推荐，需付费）

**Shadowrocket** 是 iOS 上最好用的机场客户端，一次购买永久使用。

#### 第 1 步：购买并下载 Shadowrocket

1. **切换到美区 Apple ID**（Shadowrocket 仅在美区 App Store 上架）
2. 打开 **App Store**，搜索 **Shadowrocket**
3. 购买并下载（价格：$2.99）

> **没有美区账号？** 可以在淘宝搜索"美区 Apple ID"，10-20 元购买一个临时账号下载 Shadowrocket，下载完成后退出登录即可。

#### 第 2 步：导入订阅链接

1. 打开 **Shadowrocket**
2. 点击右上角 **+** 号
3. 选择 **类型** → **Subscribe**（订阅）
4. 在 **URL** 栏粘贴你的机场订阅链接
5. 点击右上角 **完成**

#### 第 3 步：选择节点并连接

1. 点击 **全局路由** → 选择 **配置**
2. 回到首页，选择一个节点（建议选择延迟低的）
3. 点击顶部的 **开关**，允许添加 VPN 配置
4. 输入手机密码，完成连接

✅ **连接成功！** 你会在状态栏看到一个 VPN 图标。

---

### 方法二：Quantumult X（进阶用户）

**Quantumult X** 功能更强大，但配置更复杂。

#### 第 1 步：下载 Quantumult X

1. 美区 App Store 搜索 **Quantumult X**
2. 购买并下载（价格：$7.99）

#### 第 2 步：导入订阅链接

1. 打开 **Quantumult X**
2. 点击右下角 **三条杠** → **设置**
3. 找到 **节点** → **引用（订阅）**
4. 点击右上角 **+** → 粘贴订阅链接
5. 点击 **确定** → **更新**

#### 第 3 步：连接

1. 回到首页，点击 **节点** → 选择一个节点
2. 点击右上角 **开关**
3. 允许添加 VPN 配置

✅ **连接成功！**

---

### 方法三：Surge（专业用户，功能最强）

**Surge** 是 iOS 上最专业的代理工具，适合高级用户。

- **价格：** $49.99（永久版）/ $4.99/月（订阅版）
- **配置方法：** 与 Quantumult X 类似，导入订阅后选择节点连接

## 🤖 Android 配置教程

### 方法一：Clash for Android（推荐，免费）

**Clash for Android** 是 Android 上最流行的机场客户端，完全免费。

#### 第 1 步：下载 Clash for Android

1. 访问 [GitHub 官方仓库](https://github.com/Kr328/ClashForAndroid)
2. 下载最新版本的 **APK 文件**
3. 安装 APK（需要允许"安装未知来源应用"）

> **国内用户无法访问 GitHub？** 可以在机场官网查找下载链接，或使用[云图机场](/post/airport-review-yuntu)等提供客户端下载的机场。

#### 第 2 步：导入订阅链接

1. 打开 **Clash for Android**
2. 点击 **配置** → **新配置** → **从 URL 导入**
3. 粘贴你的机场订阅链接
4. 点击 **保存** → **更新**

#### 第 3 步：选择节点并连接

1. 回到首页，点击 **代理**
2. 选择 **PROXY** 或 **全局**
3. 选择一个节点（建议选择延迟低的）
4. 点击首页的 **开关**，允许创建 VPN 连接

✅ **连接成功！** 你会在状态栏看到一个钥匙图标。

---

### 方法二：V2rayNG（免费，简单）

**V2rayNG** 是另一个流行的 Android 客户端，更轻量。

#### 第 1 步：下载 V2rayNG

1. 访问 [GitHub 官方仓库](https://github.com/2dust/v2rayNG)
2. 下载最新版本的 **APK 文件**
3. 安装 APK

#### 第 2 步：导入订阅链接

1. 打开 **V2rayNG**
2. 点击左上角 **三条杠** → **订阅设置**
3. 点击 **+** → 粘贴订阅链接
4. 点击 **确定** → 返回首页
5. 点击右上角 **三个点** → **更新订阅**

#### 第 3 步：连接

1. 选择一个节点
2. 点击右下角 **V** 图标
3. 允许创建 VPN 连接

✅ **连接成功！**

## 💻 Windows 配置教程

### 方法一：Clash for Windows（推荐，免费）

**Clash for Windows** 是 Windows 上最好用的机场客户端。

#### 第 1 步：下载 Clash for Windows

1. 访问 [GitHub 官方仓库](https://github.com/Fndroid/clash_for_windows_pkg)
2. 下载最新版本的 **Setup.exe** 或 **portable.zip**
3. 安装或解压

#### 第 2 步：导入订阅链接

1. 打开 **Clash for Windows**
2. 点击左侧 **Profiles**
3. 在顶部输入框粘贴你的订阅链接
4. 点击 **Download**

#### 第 3 步：选择节点并连接

1. 点击左侧 **Proxies**
2. 选择 **GLOBAL** 或 **Proxy** 模式
3. 选择一个节点
4. 点击左侧 **General** → 打开 **System Proxy** 开关

✅ **连接成功！**

#### 常见问题

**Q: 浏览器还是无法访问 Google？**
- **A:** 检查是否开启了 **System Proxy**，确保代理模式是 **Rule**（规则）或 **Global**（全局）

**Q: Clash 无法启动？**
- **A:** 关闭杀毒软件（360、火绒等），或将 Clash 加入白名单

### 方法二：V2rayN（免费，轻量）

**V2rayN** 是另一个流行的 Windows 客户端。

#### 第 1 步：下载 V2rayN

1. 访问 [GitHub 官方仓库](https://github.com/2dust/v2rayN)
2. 下载 **v2rayN-Core.zip**
3. 解压到任意文件夹

#### 第 2 步：导入订阅链接

1. 打开 **v2rayN.exe**
2. 点击顶部 **订阅** → **订阅设置**
3. 点击 **添加** → 粘贴订阅链接
4. 点击 **确定** → **更新订阅**

#### 第 3 步：连接

1. 右键选择一个节点 → **设为活动服务器**
2. 点击顶部 **系统代理** → 选择 **自动配置系统代理**

✅ **连接成功！**

## 🍎 Mac 配置教程

### 方法一：ClashX（推荐，免费）

**ClashX** 是 Mac 上最好用的机场客户端。

#### 第 1 步：下载 ClashX

1. 访问 [GitHub 官方仓库](https://github.com/yichengchen/clashX)
2. 下载最新版本的 **ClashX.dmg**
3. 打开 DMG，将 ClashX 拖到 **Applications** 文件夹

#### 第 2 步：导入订阅链接

1. 打开 **ClashX**（菜单栏会出现一个猫图标）
2. 点击 **配置** → **托管配置** → **管理**
3. 点击 **添加** → 粘贴订阅链接
4. 点击 **确定**

#### 第 3 步：选择节点并连接

1. 点击菜单栏的 **ClashX 图标**
2. 选择 **出站模式** → **规则判断**
3. 选择一个节点
4. 点击 **设置为系统代理**

✅ **连接成功！**

## 🔧 进阶技巧

### 1. 如何测试节点速度？

**方法一：客户端内置测速**
- Clash / Shadowrocket / Quantumult X 都支持节点延迟测试
- 点击节点旁边的 **测速** 按钮

**方法二：在线测速**
- 连接节点后，访问 [Speedtest.net](https://www.speedtest.net/)
- 测试下载速度和延迟

### 2. 如何优化连接速度？

1. ✅ **选择延迟低的节点**（通常 < 100ms）
2. ✅ **避开高峰期**（晚上 8-11 点）
3. ✅ **使用游戏专线节点**（适合游戏和直播）
4. ✅ **开启 UDP 加速**（在客户端设置中）

### 3. 如何解决"无法连接"问题？

**常见原因：**
- ❌ 订阅链接过期 → 重新复制订阅链接
- ❌ 节点失效 → 换一个节点
- ❌ 防火墙拦截 → 关闭杀毒软件
- ❌ 端口被占用 → 重启客户端

**解决方法：**
1. 更新订阅（刷新节点列表）
2. 换一个节点测试
3. 重启客户端
4. 联系机场客服

## 常见问题

### Q1: 客户端下载需要科学上网吗？
**A:** 部分客户端（GitHub 下载）需要，但很多机场会提供国内可访问的下载链接。

### Q2: 可以同时在多个设备上使用吗？
**A:** 可以，但大部分机场会限制同时在线设备数（通常 3-5 个）。

### Q3: 配置后无法上网怎么办？
**A:** 
1. 检查是否开启了系统代理
2. 尝试更换节点
3. 更新订阅链接
4. 重启客户端

### Q4: 如何卸载客户端？
**A:** 
- **iOS：** 长按图标删除 + 删除 VPN 配置（设置 → 通用 → VPN）
- **Android：** 卸载 APK
- **Windows：** 控制面板卸载
- **Mac：** 拖到废纸篓
