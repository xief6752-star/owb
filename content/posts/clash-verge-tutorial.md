Clash Verge Rev 是目前 Windows 平台最主流的科学上网客户端之一，基于 Clash 核心开发，支持规则分流、多种协议，界面简洁易用。这篇教程从零开始，手把手教你配置。

## 准备工作

在开始之前，你需要：

1. **Windows 10 或 Windows 11 系统**（不支持 Windows 7 及以下版本）
2. **已购买的机场订阅**（本教程假设你已经有机场账号）
3. **基本的计算机操作能力**（会下载文件、解压、安装软件）

**预计用时**：首次配置约 10 分钟

## 第一步：下载与安装

### 1. 下载 Clash Verge Rev

访问 GitHub 官方发布页：

```
https://github.com/clash-verge-rev/clash-verge-rev/releases
```

找到最新版本（Latest），下载文件名类似 `Clash.Verge_1.x.x_x64-setup.exe` 的安装包（大小约 30-40MB）。

**⚠️ 重要提示**：

- 只从 GitHub 官方页面下载，不要从第三方网站下载，避免被植入恶意代码
- 如果你的系统是 32 位（很少见），下载 `x86` 版本
- Windows Defender 可能会误报，这是正常现象（Clash 类工具常被杀毒软件误判）

### 2. 安装软件

1. 双击下载的 `.exe` 安装包
2. 如果弹出"Windows 已保护你的电脑"提示，点击**"更多信息"** → **"仍要运行"**
3. 在安装向导中，一路点击**"下一步"**，保持默认设置即可
4. 安装完成后，桌面会出现 Clash Verge Rev 图标

### 3. 首次启动

双击桌面图标启动软件。首次启动时会弹出防火墙提示，务必点击**"允许访问"**，否则软件无法正常工作。

启动后你会看到主界面，左侧是导航菜单，右侧是主要功能区。

## 第二步：基础设置（重要，请勿跳过）

在导入订阅之前，必须先完成基础设置，否则可能导致网络中断、不稳定、流媒体解锁失效等问题。

### 1. 进入设置页面

点击左侧菜单的**"设置"**（齿轮图标）。

### 2. 必做的三个设置

在设置页面中，找到以下选项并按要求操作：

#### ① 关闭"系统代理"的自动启动（可选）

- 找到"系统代理"相关选项
- 建议**关闭"开机自启系统代理"**，改为手动控制（避免开机自动连接）

#### ② 关闭 IPv6

- 找到"IPv6"开关
- 将其**关闭**（设置为 OFF）
- **原因**：国内网络环境对 IPv6 支持不完善，开启可能导致部分网站无法访问或解析错误

#### ③ 打开"统一延迟"

- 找到"统一延迟"（Unified Delay）开关
- 将其**打开**（设置为 ON）
- **原因**：这会让延迟测试更准确，帮你找到最快的节点

### 3. 其他推荐设置

- **主题**：可以选择"亮色"或"暗色"主题，根据个人喜好
- **语言**：如果界面是英文，可以在"Language"中切换到"简体中文"

完成设置后，点击右上角的**"保存"**或**"应用"**（如果有）。

## 第三步：导入机场订阅

### 1. 获取订阅链接

登录你购买的机场后台（每个机场界面不同），找到以下内容：

- 通常在"订阅"、"使用文档"、"节点订阅"等菜单
- 选择 **Clash** 格式的订阅链接（不是 V2Ray、Shadowrocket 等其他格式）
- 复制订阅链接（通常以 `https://` 开头，以 `&flag=clash` 或类似参数结尾）

**常见订阅链接格式示例**：

```
https://example.com/api/v1/client/subscribe?token=abc123&flag=clash
```

### 2. 在 Clash Verge Rev 中导入订阅

1. 点击左侧菜单的**"订阅"**（或"配置文件"、"Profiles"）
2. 在页面顶部找到**"从 URL 导入"**或类似按钮
3. 将复制的订阅链接粘贴到输入框
4. （可选）给订阅起个名字，比如"我的机场"
5. 点击**"导入"**或**"确定"**

软件会自动下载订阅配置，几秒钟后，你会在订阅列表中看到刚才导入的配置文件。

### 3. 启用订阅

在订阅列表中，找到刚才导入的配置文件，点击**"启用"**或**"切换"**按钮（通常是一个开关图标），使其变为激活状态（绿色或高亮显示）。

## 第四步：选择节点并开始使用

### 1. 查看节点列表

点击左侧菜单的**"代理"**（或"节点"、"Proxies"），你会看到机场提供的所有节点列表，通常按地区分组：

- 🇭🇰 香港节点
- 🇯🇵 日本节点
- 🇺🇸 美国节点
- 🇸🇬 新加坡节点
- ……

### 2. 选择节点

#### 方式一：手动选择（推荐新手）

在节点列表中，直接点击你想用的节点。通常选择：

- **香港节点**：延迟最低，适合日常浏览、YouTube、ChatGPT
- **日本节点**：适合看日本 Netflix、游戏加速
- **美国节点**：适合看美区 Netflix、Disney+

#### 方式二：延迟测试（推荐）

1. 点击节点列表上方的**"延迟测试"**按钮（闪电图标或"Delay Test"）
2. 软件会自动测试所有节点的延迟，显示 ms 数值（越低越快）
3. 选择延迟最低的节点（通常是香港节点，10-50ms）

### 3. 开启系统代理

完成节点选择后，回到主界面，找到**"系统代理"**开关，将其**打开**（设置为 ON）。

此时，你的电脑所有流量都会通过选中的节点，可以访问外网了。

### 4. 测试是否成功

打开浏览器，访问以下网站测试：

- **Google**：https://www.google.com
- **YouTube**：https://www.youtube.com
- **IP 检测**：https://ip.sb （查看你当前的 IP 地址，应该显示为节点所在国家/地区）

如果能正常访问，说明配置成功！

## 第五步：进阶功能（可选）

### 1. 规则模式选择

Clash Verge Rev 支持三种代理模式，可以在主界面切换：

- **规则模式（Rule）**：推荐！自动分流，国内网站直连，国外网站走代理，速度快且省流量
- **全局模式（Global）**：所有流量走代理，包括国内网站，慢且费流量
- **直连模式（Direct）**：所有流量不走代理，相当于关闭

**新手推荐**：保持"规则模式"即可。

### 2. 节点自动选择

部分机场订阅支持"自动选择"功能：

- 在节点列表中找到"自动选择"或"Auto"分组
- 选中它，软件会根据延迟自动切换到最快节点
- 适合懒人用户，但有时不如手动选择精准

### 3. 订阅更新

机场会定期更新节点信息（增加新节点、删除失效节点），建议每周更新一次订阅：

1. 进入"订阅"页面
2. 找到你的订阅，点击旁边的**"更新"**按钮（刷新图标）
3. 等待几秒，订阅配置就更新了

### 4. 开机自启（可选）

如果你希望开机后自动连接：

1. 进入"设置"页面
2. 找到"开机自启"或"Launch at Startup"
3. 打开开关

**注意**：如果你不是重度用户，不建议开启，避免忘记关闭导致流量浪费。

## 常见问题解答

### Q1: 安装后打开软件，提示"缺少 xxx.dll 文件"

**A**: 缺少系统运行库。解决方法：

1. 下载并安装 **Microsoft Visual C++ Redistributable**（微软官方运行库）
2. 访问：https://aka.ms/vs/17/release/vc_redist.x64.exe
3. 安装后重启电脑

### Q2: 导入订阅后看不到节点

**A**: 可能的原因：

1. **订阅链接错误**：检查是否复制了完整的链接，确认选择了"Clash"格式
2. **订阅已过期**：登录机场后台，确认账号是否还有剩余流量和时间
3. **网络问题**：软件首次导入订阅需要联网，确保你的网络正常

### Q3: 开启系统代理后，部分国内网站打不开

**A**: 这是规则配置问题。解决方法：

1. 确认你使用的是"规则模式"而非"全局模式"
2. 更新订阅（机场会不定期优化规则）
3. 如果问题依旧，尝试切换到其他节点

### Q4: YouTube 能打开但是很卡，视频加载慢

**A**: 可能的原因：

1. **节点拥挤**：切换到其他节点，或使用"延迟测试"找最快的
2. **晚高峰**：晚上 8-11 点是网络高峰期，速度会变慢，这是正常现象
3. **机场质量**：如果所有节点都很慢，可能是机场本身质量不行，考虑换机场

### Q5: 软件启动后，电脑无法上网

**A**: 系统代理冲突。解决方法：

1. 关闭 Clash Verge Rev 的"系统代理"开关
2. 打开 Windows 设置 → 网络和 Internet → 代理
3. 确认"自动检测设置"是关闭的，"手动代理设置"也是关闭的
4. 重新打开 Clash Verge Rev 的"系统代理"

### Q6: 更新 Windows 后，软件无法启动

**A**: Windows 大版本更新可能导致兼容性问题。解决方法：

1. 卸载当前版本的 Clash Verge Rev
2. 重新下载最新版本安装
3. 重新导入订阅（之前的订阅链接还在，直接粘贴即可）

## 安全与隐私提示

1. **不要在公共 WiFi 环境下使用机场**：公共 WiFi 不安全，可能被监听
2. **定期更新软件**：新版本通常修复了安全漏洞
3. **不要分享你的订阅链接**：订阅链接相当于你的账号密码，泄露后别人可以用你的流量
4. **遵守当地法律法规**：科学上网只是工具，用它获取信息、学习知识，不要做违法的事

完成以上步骤，你已经成功配置好 Clash Verge Rev 了！日常使用很简单：

1. 打开软件
2. 确认节点已选择
3. 打开"系统代理"开关
4. 开始浏览

如果遇到其他问题，可以参考机场的使用文档，或在社区（如 V2EX、GitHub）搜索相关讨论。
