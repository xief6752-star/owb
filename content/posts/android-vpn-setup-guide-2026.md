Android 手机科学上网相比 iOS 更加简单和自由，客户端选择多、配置灵活、无需额外购买。本教程将手把手教您完整的 Android 翻墙流程。

## 一、Android 翻墙的优势

### ✅ 相比 iOS 的优势

| 对比项 | Android | iOS |
|--------|---------|-----|
| **客户端获取** | 免费下载 APK | 需要美区 ID + 付费 |
| **安装方式** | 直接安装 APK | App Store 下载 |
| **客户端选择** | 非常多 | 相对较少 |
| **配置灵活性** | 高度自定义 | 相对受限 |
| **更新便捷性** | 随时更新 | 依赖 App Store |

**结论：** Android 翻墙更简单、更自由、更便宜！

## 四、方案 A：Clash for Android（推荐）

### 步骤 1：下载 Clash for Android

#### 方法 1：GitHub 下载（推荐）

1. **访问 GitHub 官方仓库**
   ```
   github.com/Kr328/ClashForAndroid
   ```

2. **下载 APK**
   - 点击 "Releases"
   - 找到最新版本
   - 下载对应的 APK 文件

**文件名示例：**
```
cfa-2.5.12-foss-universal-release.apk
```

⚠️ **版本选择：**
- `foss` 版本：开源版（推荐）
- `premium` 版本：高级版（需付费）
- `universal` 版本：通用版（适合所有设备）

---

#### 方法 2：国内镜像下载

如果 GitHub 无法访问，可以从以下渠道下载：

**可靠来源：**
1. 机场官网的客户端下载页
2. APKMirror.com
3. 云盘分享（确保来源可信）

⚠️ **安全提示：** 
- 只从官方或可信来源下载
- 下载后检查 SHA256 哈希值
- 避免从不明第三方网站下载

---

### 步骤 2：安装 Clash for Android

1. **找到下载的 APK 文件**
   - 打开"文件管理器"
   - 进入"Download"文件夹

2. **安装 APK**
   - 点击 APK 文件
   - 如果提示"禁止安装未知应用"：
     - 点击"设置"
     - 允许该来源安装应用
     - 返回继续安装

3. **完成安装**
   - 点击"安装"
   - 等待安装完成
   - 点击"打开"

---

### 步骤 3：获取订阅链接

1. **登录你的机场网站**

2. **找到订阅中心**
   - 常见位置：
     - "订阅中心"
     - "客户端下载"
     - "使用教程"

3. **复制订阅链接**
   - 选择 "Clash" 或 "通用订阅"
   - 点击"复制订阅链接"

**示例：**
```
https://example.com/api/v1/client/subscribe?token=xxxxx
```

⚠️ **重要：** 订阅链接是私密信息，不要泄露给他人！

---

### 步骤 4：导入订阅配置

#### 方法 1：URL 导入（推荐）

1. **打开 Clash for Android**

2. **添加配置**
   - 点击顶部 "配置"（Profiles）
   - 点击右上角 "+"

3. **选择导入方式**
   - 选择 "URL"

4. **粘贴订阅链接**
   - 名称：填写机场名称（如：云图）
   - URL：粘贴订阅链接
   - 自动更新：建议开启（间隔 24 小时）

5. **下载配置**
   - 点击"保存"
   - 等待配置下载完成
   - 看到配置文件名称，表示成功

---

#### 方法 2：扫码导入

1. 在机场网站找到订阅二维码
2. 打开 Clash for Android
3. 配置 → + → 扫描二维码
4. 扫描订阅二维码
5. 自动导入配置

---

### 步骤 5：选择代理模式

**点击底部 "代理"（Proxies）**

**三种模式说明：**

| 模式 | 说明 | 使用场景 |
|------|------|----------|
| **规则（Rule）** | 自动分流 | 日常使用 ⭐推荐 |
| **全局（Global）** | 全部走代理 | 访问纯外网 |
| **直连（Direct）** | 不走代理 | 临时关闭代理 |

**推荐：规则模式**（国内直连、国外代理）

---

### 步骤 6：选择节点

1. **点击代理策略组**
   - 常见策略组：
     - "选择代理"
     - "自动选择"
     - "香港节点"
     - "日本节点"

2. **测试延迟**
   - 点击策略组
   - 点击右上角"测试延迟"图标
   - 等待测试完成
   - 绿色数字 = 延迟（越小越好）

3. **选择节点**
   - 点击延迟最低的节点
   - 或选择需要的地区节点

**推荐节点：**
- 日常：香港（延迟 10-30ms）
- 游戏：日本游戏专线（延迟 40-60ms）
- 流媒体：对应地区节点

---

### 步骤 7：启动代理

1. **返回首页**
   - 点击底部"首页"

2. **点击启动按钮**
   - 点击中间的大按钮
   - 首次使用会弹出 VPN 连接请求

3. **允许 VPN 连接**
   - 点击"确定"
   - Android 会显示"正在建立 VPN 连接"

4. **查看状态**
   - 通知栏出现"🔑"图标
   - Clash 显示"已运行"
   - 表示已成功连接

5. **验证连接**
   - 打开浏览器
   - 访问 google.com
   - 能正常打开说明成功！✅

**GitHub 下载：**
```
github.com/2dust/v2rayNG
```

**安装步骤同 Clash**

---

### 导入订阅

1. **打开 V2rayNG**

2. **添加订阅**
   - 点击左上角 "☰"
   - 订阅分组设置
   - 点击 "+"

3. **填写订阅信息**
   - 备注：机场名称

   - 自动更新：开启

   - 返回首页

### 启动代理

1. **选择节点**

   - 或点击右上角测试全部

3. **启动连接**
   - 点击右下角 ▶️ 按钮
   - 允许 VPN 连接

## 六、进阶设置

### 1. Clash 自定义规则

**路径：** 配置 → 点击配置文件 → 编辑

**常用规则：**

```yaml
rules:
  # ChatGPT 走美国节点
  - DOMAIN-SUFFIX,openai.com,🇺🇸美国
  
  # Netflix 走新加坡
  - DOMAIN-KEYWORD,netflix,🇸🇬新加坡
  
  # 游戏走游戏专线
  - DOMAIN-KEYWORD,steam,🎮游戏专线
  
  # 国内网站直连
  - DOMAIN-SUFFIX,baidu.com,DIRECT
  - DOMAIN-SUFFIX,qq.com,DIRECT
```

---

### 2. 分应用代理

**Clash for Android 支持：**

**路径：** 设置 → 网络 → 访问控制

**模式选择：**
- **允许选中应用**：只有选中的 App 走代理
- **绕过选中应用**：选中的 App 不走代理

**使用场景：**
- 只让浏览器走代理（省流量）
- 银行类 App 不走代理（安全）
- 国内游戏不走代理（避免延迟）

---

### 3. 订阅自动更新

**Clash 设置：**
- 配置 → 长按配置 → 编辑
- 自动更新：开启
- 更新间隔：24 小时

**好处：**
- 自动获取最新节点
- 无需手动更新
- 保持节点可用性

---

### 4. 流量统计

**Clash 查看：**
- 首页 → 点击流量图标
- 查看今日/本周/本月用量

**设置流量提醒：**
- 设置 → 通知
- 开启流量提醒
- 设置阈值（如剩余 10%）

## 七、常见问题解决

### 问题 1：无法下载配置

**原因：**
- 订阅链接错误
- 网络问题
- 订阅已过期

**解决方法：**

1. **检查订阅链接**
   - 确保链接完整
   - 没有多余空格

2. **切换网络**
   - 尝试切换 WiFi/4G

3. **检查订阅状态**
   - 登录机场网站
   - 确认账号有效
   - 确认流量未用完

---

### 问题 2：连接后无法上网

**原因：**
- VPN 权限未授予
- 节点不可用
- DNS 问题

**解决方法：**

1. **检查 VPN 权限**
   - 设置 → 应用 → Clash
   - 确认 VPN 权限已开启

2. **更换节点**
   - 测试延迟
   - 选择可用节点

3. **更改 DNS**
   - Clash：设置 → 覆写 → DNS
   - 改为：8.8.8.8 或 1.1.1.1

---

### 问题 3：速度慢

**原因：**
- 节点负载高
- 本地网络问题
- 高峰期拥堵

**解决方法：**

1. **更换节点**
   - 选择延迟更低的
   - 避开热门节点

2. **更换代理模式**
   - 试试直连模式（排除本地网络问题）

3. **升级套餐**
   - 考虑更高级的套餐

---

### 问题 4：国内应用打不开

**原因：**
- 使用了全局模式
- 分应用代理设置错误

**解决方法：**

**Clash：**
- 改为"规则模式"
- 或在分应用代理中排除国内 App

**V2rayNG：**
- 设置 → 路由 → 预定义规则
- 选择"绕过大陆地址"

---

### 问题 5：电池耗电快

**原因：**
- 后台持续运行
- 频繁测试延迟
- 某些客户端优化不佳

**解决方法：**

1. **关闭不必要的功能**
   - 关闭自动测速
   - 减少自动更新频率

2. **使用省电客户端**
   - V2rayNG 较省电
   - Clash Meta 功耗较高

3. **临时关闭代理**
   - 不需要时关闭
   - 使用时再开启
